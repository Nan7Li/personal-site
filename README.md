# 我的个人主页

简体中文响应式静态网站，使用 HTML 和 CSS，无框架、无依赖、无 JavaScript。

网站内容位于 `public/`。修改 `public/index.html` 更新文案，修改 `public/styles.css` 调整样式。

## Cloudflare Pages

- 连接此 GitHub 仓库，生产分支 `main`
- 框架预设：None
- 构建命令：留空
- 构建输出目录：`public`
- 使用免费 `pages.dev` 地址，不绑定自定义域名
